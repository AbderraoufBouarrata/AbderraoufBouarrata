## 🏠 The homelab

A single Proxmox host built around security and privacy: no third party gets to see the data.

| Service                   | Purpose                                 |
| ------------------------- | --------------------------------------- |
| **Proxmox Backup Server** | Backups for the virtual machines        |
| **WireGuard**             | Remote access without exposing services |
| **Caddy**                 | Reverse proxy and HTTPS                 |
| **Pi-hole**               | Network ad blocking                     |
| **Immich**                | Self-hosted photo library               |
| **Uptime Kuma**           | Monitoring                              |
| **Game servers**          | Multiplayer game hosting                |
