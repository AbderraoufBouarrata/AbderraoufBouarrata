## 👋 About me

I'm **Raouf**, a Senior Frontend Engineer from Algeria with more than four years of experience.

- ⚛️ I specialise in **React** and **Next.js**, written in **TypeScript**
- 📱 I ship mobile apps with **React Native** and **Expo**
- 🛠️ I build backends with **NestJS** and **Node.js**

- 🖥️ I run a self-hosted **Proxmox** homelab, built around privacy
- ☁️ I'm currently growing into **cloud, DevOps and platform engineering**

## 🏠 The homelab

A single Proxmox host where privacy comes first: no third party gets to see the data.

| Service                   | Purpose                                                  |
| ------------------------- | -------------------------------------------------------- |
| **Proxmox Backup Server** | Backups for the virtual machines                         |
| **WireGuard** (wg-easy)   | Remote access without exposing services                  |
| **Caddy**                 | Reverse proxy and HTTPS                                  |
| **Pi-hole**               | Network ad blocking                                      |
| **Immich**                | Self-hosted photo library                                |
| **Uptime Kuma**           | Monitoring                                               |
| **Game servers**          | Minecraft, Don't Starve Together and Valheim for friends |
